## 2026-04-23 项目仓库规则
- `workspace/projects` 目录不要提交到 workspace 根仓库。
- `projects/` 下每个项目文件夹都是独立 git 项目。
- 新项目应在各自项目目录内执行 `git init`，例如 `workspace/projects/wedding-carousel-web/`。

## 2026-04-23 婚礼轮播网页项目方向
- 新项目：`projects/wedding-carousel-web/`
- 技术路线确认：React + GSAP
- 核心要求之一：支持静态页面，并能方便使用图片素材 CDN URL 作为数据源。
- 播放模式：同时支持自动轮播 autoplay 和叙事式 story scroll，两者都要，艺术性优先。
- 屏幕适配：默认 16:9 横屏，但兼容竖屏手机播放。
- 控制方式：默认纯自动播放。
- 内容层级：纯图片为主，文案弱化。
- 音乐：支持背景音乐自动播放，手机端提供悬浮播放开关。
- 图片现状：单张高清图平均约 10MB，需要考虑加载进度条与本地缓存。
